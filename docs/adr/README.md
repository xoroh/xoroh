# Architecture Decision Records

Numbered records of cross-project decisions. Project-scoped decisions live in
the project repository; only ecosystem-wide decisions live here.

## Conventions

- Files: `docs/adr/NNNN-short-title.md` (`0000-template.md` is the template,
  never a decision).
- Status: `proposed` → `accepted` | `rejected` → `superseded by ADR-NNNN`.
- Status changes require owner approval and a dated entry; never silently
  mark a proposal as accepted.
- Each ADR records context, decision, alternatives, and consequences.
