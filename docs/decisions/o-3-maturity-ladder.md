# O-3 — Maturity ladder: CNCF-style

Status: accepted 2026-10-16 (director).

## Decision

Adopt a CNCF-style ladder: Sandbox → Incubating → Graduated (+ Archived
rule), with published entry/exit evidence.

## Seeding at 0.1.0

- Kern → **Incubating**: docs site + quality gates + dual-renderer contract.
- Axis → **Sandbox**: file-docs + example only.

Pre-release the site shows these as target badges, never as earned stages.
The full `/maturity` page (criteria + evidence) ships with the TanStack
port (O-1 staging).
