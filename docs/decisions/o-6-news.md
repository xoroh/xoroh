# O-6 — News: a single `/news` stream

Status: accepted 2026-10-16 (director).

## Decision

One news stream (`/news`; v0: `news.html`) for releases, governance notes,
and security notes. Split into blog/announcements only when sustained
volume (>1 post/month) demands it.

## Consequences

The stream starts at launch — no backfill. First entries: Kern 0.1.0 +
Axis 0.1.0 release notes, a governance note, and a security-policy note.
