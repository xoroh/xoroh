# Security Policy

## Supported versions

The repository has not published a versioned release. Until then, report issues against the current `main` branch.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/xoroh/xoroh/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include the affected commit, impact, and reproduction steps. The maintainers will acknowledge and coordinate reports as promptly as possible; please allow time to investigate and prepare a fix before public disclosure.
